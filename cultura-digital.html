🎨 Teoría del color

La teoría del color estudia cómo se combinan los colores y cómo influyen en nuestras emociones.

Tipos de colores:

  • 🔴 Primarios: rojo, azul, amarillo
  • 🟠 Secundarios: naranja, verde, morado
  • 🟡 Terciarios: mezcla de primarios y secundarios

Combinaciones:

  • Complementarios: colores opuestos
  • Análogos: colores cercanos
  • Triádicos: tres colores equilibrados

Importancia: Hace los diseños más atractivos y mejora la comunicación visual.

⌨️ Combinaciones del teclado

Son atajos que ayudan a trabajar más rápido en la computadora.

Ejemplos:

  • Ctrl + C → Copiar
  • Ctrl + X → Cortar
  • Ctrl + V → Pegar
  • Ctrl + Z → Deshacer
  • Ctrl + Y → Rehacer
  • Ctrl + A → Seleccionar todo
  • Ctrl + S → Guardar
  • Alt + Tab → Cambiar ventanas

Ventaja: Ahorran tiempo y aumentan la productividad.
